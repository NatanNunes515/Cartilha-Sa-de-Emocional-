# Cartilha de Saúde Emocional

Projeto em HTML, CSS e JavaScript pronto para publicar no GitHub Pages.

## Como publicar no GitHub

1. Crie um repositório no GitHub.
2. Envie o arquivo `index.html`.
3. Vá em **Settings** > **Pages**.
4. Em **Branch**, escolha **main** e a pasta **/** (root).
5. Salve.
6. O GitHub vai gerar um link público do site.

## Estrutura
- `index.html` → site completo
